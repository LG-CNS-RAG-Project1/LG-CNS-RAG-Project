# 시장 조사 실험 기록

시장 조사(파트 3)의 기준 성능(Baseline)과 이후 실험·결정을 한곳에 모은 기록이다. 수치는 모두 `evaluation/results/`의 결과 파일에서 다시 계산한 값이며, 실험별 상세 해석은 [docs/market_research.md](market_research.md)에 있다.

## 공통 조건

| 항목 | 내용 |
|---|---|
| 평가 아이디어 | `data/samples/ideas.json` SF-01~SF-05 (평가 시점 SF-05는 이전 '현장 작업자용 LLM 음성 어시스턴트') |
| 문항 | 아이디어 × 5개 차원(수요·경쟁/대체재·가격·구매자·도입장벽) = 25문항. SF-05 라벨이 현재 SF-05(지능형 공정제어)와 맞지 않아 최신 비교는 SF-01~04 20문항 |
| 정답 라벨 | 문항별 관련 `source_id`. 사람 블라인드 + LLM(gpt-4o) 초안 후 확신 낮은 행 사람 검토 (`evaluation/labels/`, 절차는 `evaluation/market_labeling.md`) |
| 검색 자료 | 네이버 뉴스 제목·요약 (평가 시점 1,895건). DART 사업보고서는 정답 라벨이 없어 검색 평가에서 제외 |
| 임베딩 | `text-embedding-3-small`, Chroma cosine |

## 실험 1: 검색 방식 비교 (20문항, SF-01~04)

| 방식 | Hit@5 | Recall@5 | Precision@5 | MRR | nDCG@5 | 응답 시간 |
|---|---|---|---|---|---|---|
| dense (기본) | 0.95 | 0.38 | 0.46 | 0.60 | 0.47 | 411ms |
| BM25 | 0.60 | 0.18 | 0.32 | 0.41 | 0.32 | 107ms |
| hybrid | 0.80 | 0.29 | 0.45 | 0.58 | 0.46 | 346ms |

- 25문항(이전 SF-05 포함)에서는 hybrid가 MRR 0.61 · nDCG@5 0.48로 dense(0.59 · 0.45)보다 조금 높았으나, 현재 아이디어와 맞는 20문항에서는 우위가 사라졌다.
- BM25는 기술 용어는 잘 맞히지만 '가격·비용·어려움' 같은 차원 표현이 흔한 단어라 가중치가 낮아 가격·도입장벽 차원에서 무관한 기사를 올린다.
- 라벨 후보를 세 방식 상위 5건으로 넓혀 정답 문서가 늘었기 때문에 dense의 Recall@5(0.38)는 Baseline(0.45)보다 낮게 나온다. 같은 방식의 성능이 떨어진 것이 아니다.
- 결과: `evaluation/results/market_retrieval_{dense,bm25,hybrid}_extended20.csv`

## 실험 2: 충분성 판정·관련성 판정 모델

| 판정 (사람 라벨 91행) | 정확도 | 정밀도 | 재현율 | kappa |
|---|---|---|---|---|
| 필터 없음 (상위 5건 전부 근거) | - | 0.54 | 1.00 | - |
| gpt-4o | 0.76 | 0.89 | 0.63 | 0.52 |
| gpt-4o-mini | 0.68 | 0.69 | 0.73 | 0.36 |
| gpt-4o-mini + 근거 성격 (현재) | 0.71 | 0.72 | 0.78 | 0.42 |

- 검색 거리는 관련성이 아니라 아이디어 주제와의 근접도를 반영해, 관련/비관련을 거리로 나누면 AUC 0.52(도입장벽 0.33)였다.
- 아이디어 1건에 판정 25회가 전체 토큰의 약 90%라 비용 때문에 mini를 쓴다. mini는 정밀도가 낮아 무관한 기사가 근거로 더 들어온다.
- 사람·LLM 판정이 달랐던 행은 LLM 판정을 본 뒤 확정했으므로 앵커링 가능성이 있다.
- 결과: `evaluation/results/market_relevance_{gpt-4o,gpt-4o-mini,mini-nature}.csv`

## 실험 3: 답변 품질 (LLM 단독 vs RAG)

| 지표 (20문항) | LLM 단독 | 단순 RAG | IdeaLens |
|---|---|---|---|
| 판정 (확인됨 / 신호만 / 미확인) | 0 / 0 / 20 | 4 / 14 / 2 | 3 / 16 / 1 |
| 뉴스만으로 수요 '확인됨' (과대 판정) | 0 | 1 | 0 |
| 사실 문장 | 0 | 37 | 30 |
| 인용 없는 사실 문장 | - | 2.7% | 0% |
| Citation Accuracy (판정기) | - | 0.83 | 1.00 |
| **Citation Accuracy (사람 검토 보정)** | - | **0.43** | **0.87** |
| 인용 기사 관련 비율 (사람 정답 라벨) | - | 0.73 | 0.83 |

- LLM 단독은 자료가 없다고 밝히고 추정 문장만 냈다. 단순 RAG는 한 기업 사례를 시장 수요로 넓히는 과잉 일반화가 많았다(사람 검토 15문장 중 partial 6 · unsupported 3).
- 문장 판정기(gpt-4o-mini)와 사람의 일치율은 0.67(kappa 0.24)로 판정기가 관대해, 사람 검토 비율로 보정한 값을 주 지표로 쓴다.
- 결과: `evaluation/results/market_answer_{,claims_,summary_}baseline.csv`, `market_answer_agreement_baseline.json`

## 오류 개선 기록 (라벨 평가가 아닌 실행 결과 비교)

정답 라벨로 잰 값이 아니라 같은 샘플 아이디어의 실행 결과를 수정 전후로 비교한 기록이다. DART 기업 선택·청크·성격 수정은 #63으로 반영됐고, 검색 관심도(#68)와 주식 기사 수정은 PR 머지 후 반영된다.

| 문제 | 수정 전 | 수정 | 수정 후 |
|---|---|---|---|
| mini 분석이 근거 약한 차원을 '확인됨'으로 판정 | 샘플 5건 모두 경쟁 차원 `confirmed` | 근거가 사업 신호·기업 주장·추정치뿐이면 코드에서 `confirmed` 불허 | `confirmed` 0~3개 (구매 신호 인용 시만) |
| DART 인용 문장에 공시 기업명 누락 | 기업 설명이 시장 사실처럼 읽힘. 검증 실패로만 처리하면 DART 인용 차원 12 → 1 | 기업명이 없으면 "기업 사업보고서(FY연도)에 따르면" 접두어 | DART 인용 문장 모두 기업 표기 |
| 화면 경로(아이디어 필터 없음)에서 무관한 DART 기업이 DART 몫 차지 | SF-03 DART 10건 중 5건이 고영(의료로봇), DART 근거 0건 | 아이디어 전체 문장으로 가까운 기업 3곳을 먼저 고르고 기업당 1건 | 선택 기업이 SF-01·SF-02 연결 기업 3/3. SF-03은 1위만 연결 기업, 근거 0건(자료 부족) |
| DART 청크가 문장 중간에서 시작 | 346건 중 339건(98%), 인용문이 단어 중간에서 시작 | 다음 청크를 겹침 구간의 첫 줄·문장 시작에서 시작 | 313건 중 0건 |
| 표를 뺀 DART 매출 본문을 구매 신호로 분류 | "폭넓은 고객층을 대상으로 한다"는 기업 설명으로 SF-01 구매자 `confirmed` | DART 본문은 모두 기업 주장 | 해당 오판 사라짐 |
| 주식 기사를 구매 신호로 분류 | "2차전지 장비 관련주 '웃음꽃'" 기사로 SF-02 구매자 `confirmed` | 제목에 주식·투자 표현이 있으면 사업 신호 | 샘플 구매 신호 3건 중 주식 기사 1건 제외, 실제 도입 보도 2건 유지 |
| 검색 관심도가 플랫폼 전체 감소를 반영 | 원 검색량으로 비전검사 -37% · FEMS -36% 둔화 | 기준 주제어(스마트공장, -34%) 대비 지수 | 비전검사 +0.9% · FEMS +3.7% 유지 |

## 해석할 때 주의할 점

- **실험 3은 현재 서비스와 설정이 다르다.** 측정 당시 분석 모델은 gpt-4o, 근거는 뉴스만이었다. 현재 서비스는 분석·판정 모두 gpt-4o-mini이고 DART 사업보고서·기업 선택·성격 규칙이 더해졌다. 같은 설정으로 다시 재려면 사람 검토(30문장)를 다시 해야 한다.
- 각 실험은 1회 실행 결과다. 관련성 판정·분석은 실행마다 조금씩 달라져 근거 수와 판정이 바뀔 수 있다.
- 사람 검토 표본이 작다(관련성 91행, 답변 방식당 15문장). 가드레일 문항은 프롬프트 작성자가 만든 것이라 실제 공격보다 쉬울 수 있다.
- 시장 판정의 '확인됨'은 고객 검증 자료가 있을 때만 수요에 쓴다. 뉴스·공시·검색 관심도는 사업 신호이며 수요 확인이 아니다.

## 다시 실행하기

명령은 README의 평가 절을 따른다. 검색 비교는 `python -m evaluation.evaluate market --idea-ids SF-01,SF-02,SF-03,SF-04 --mode {dense,bm25,hybrid} --label refreshed`, 관련성은 `python -m evaluation.evaluate relevance`, 답변 비교는 `python -m evaluation.market_answer_eval run` → `sample` → `agreement`.
