# 빠른 조사 화면 실행·시연

```powershell
python -m pip install -r requirements-ui.txt
python -m streamlit run frontend/app.py --server.address 127.0.0.1 --server.port 8505
```

1. 큰 입력란에 아이디어를 작성하거나 예시를 불러온다. 우측은 세션의 최근 입력이다.
2. 구성·검토 질문 확인에서 최대 7개 항목을 편집·이동·삭제한 뒤 조사를 시작한다.
3. 좌측 구성, 중앙 특허·시장 후보, 우측 선택 목록을 확인한다. 자동 연결 결과를 먼저 보고, 필요할 때 문헌을 추가·제외한다.
4. 최소 2건 선택 후 종합 보고서 생성. 양쪽 조사 자료가 있는지 확인한다.
5. 보고서는 선택 문헌만 담는다. 메모 입력 후 Markdown을 내려받는다.

AI 추출·실제 검색·가격 수집·병렬 분석은 미연결이다. 예시는 가상 자료이며 사용자 입력에는 예시 분석을 적용하지 않는다. [참고 구조·구현 경계](quick-research-ui.md)를 확인한다.


홈 로고와 상단 단계 버튼으로 돌아가 확인할 수 있다. 2단계에서 구성과 검토 질문·도입 조건을 확정하고, 3단계 ‘자동 연결 결과’에서 연결 이유·조건 차이·반대 근거·다음 검증을 확인한다. 판단 과정은 펼쳐 읽고, 수정은 필요한 경우에만 한다. 4단계 표와 원문을 대조하고 다운로드한다. 메모와 선택은 화면 이동 시 유지된다.

입력·질문을 수정하면 재확정하고 연결을 다시 확인해야 한다. 근거 선택과 연결 저장·제외 후에는 보고서를 다시 생성한다. 양쪽 근거를 골라도 검증 완료가 아니다. 예시 자동 초안·사용자 수정·판단 보류를 구분한다.
