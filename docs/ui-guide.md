# 기업분석 UI 실행·시연 가이드

## 화면의 목적

스마트팩토리 기업의 사업·시장·특허를 같은 항목으로 비교하고, 비교 내용의 근거와
미확인 사항을 함께 확인하는 화면이다. 기업 비교표의 배치와 사용 흐름을 검토하기
위한 시연이며, 실제 기업 분석 API는 연결하지 않는다.

가상 A사·B사와 가상 문헌은 화면 예시로만 사용한다. 실제 기업명을 입력해도 가상
근거를 그 기업의 분석 결과로 바꾸지 않는다. API 키 없이 실행하며 입력을 외부
서비스로 보내지 않는다.

## 로컬 실행

저장소 루트에서 Windows PowerShell로 실행한다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
.\.venv\Scripts\python.exe -m streamlit run frontend/app.py
```

VS Code의 Python 인터프리터도 `.venv\Scripts\python.exe`로 선택한다.

## 화면을 읽는 순서

1. **분석 범위:** 비교 기업, 기술 분야, 기간과 질문을 확인한다.
2. **기업 비교:** 같은 항목에 대한 두 기업의 차이를 나란히 읽는다.
3. **관점 전환:** 경영진 요약에서 핵심 차이를, R&D 상세에서 기술 구성을 확인한다.
4. **근거 확인:** 인용을 선택하면 오른쪽 패널에서 문헌 정보와 원문 예시를 확인한다.
5. **다음 조사:** 미확인 사항을 보고 추가로 확보할 자료를 정한다.

화면 상단의 시연 표시와 문헌의 가상 표시를 함께 확인한다. 특허에 기술이 기재돼
있다는 사실과 실제 제품 적용·고객 실적이 확인됐다는 판단은 별개다.

## 시연·검토 순서

| 순서 | 확인할 동작 | 기대 결과 |
|---|---|---|
| 예시 보기 | 가상 기업 비교 예시 열기 | 기업·문헌이 가상이라는 표시가 유지됨 |
| 비교 읽기 | 경영진·R&D 관점 전환 | 같은 조사 범위에서 읽는 정보만 달라짐 |
| 근거 선택 | 인용 또는 문헌 선택 | 선택한 근거의 제목·구절·구획이 함께 바뀜 |
| 범위 변경 | 기업·분야·기간·질문 수정 | 적용된 범위와 편집 중인 입력을 혼동하지 않음 |
| 직접 입력 | 실제 기업명으로 범위 설정 | 가상 기업의 내용을 실제 기업에 귀속하지 않음 |
| 보고서 확인 | 다운로드 내용 읽기 | 조사 범위, 시연 표시, 근거와 미확인 사항 포함 |
| 작은 화면 | 좁은 창에서 사용 | 비교와 근거가 읽는 순서대로 배치되고 조작 가능 |

‘시연 상태 설정’에서 일부 자료 없음·검색 결과 없음·수집 오류를 고르고 ‘비교 화면 보기’를
누르면 해당 상태를 확인할 수 있다. ‘예시 다시 불러오기’는 범위와 검토 체크를 초기화한다.
실제 API를 붙일 때 재시도와 부분 실패도 검증한다. 자료 미확보를 기업의 기술 부재로 표현하지 않는다.

## 수정할 곳

- `frontend/app.py`: 범위 입력, 비교 화면, 근거 선택과 결과 표시.
- `frontend/demo.py`: 외부 호출 없는 예시 데이터와 시연 보고서.
- `frontend/styles.css`, `.streamlit/config.toml`: 화면 간격·색상·테마.
- `tests/test_frontend.py`: 입력·상태·근거 선택·시연 표시 검증.
- `docs/ui-design.md`: 배치·시각 디자인의 의도와 참고 자료.
- `docs/ui-collaboration.md`: 담당자별 연결 조건과 합의할 데이터.

## 검증과 공유

```powershell
.\.venv\Scripts\python.exe -m black --check .
.\.venv\Scripts\python.exe -m pytest
```

자동 검사 뒤 실제 브라우저에서 범위 입력, 관점 전환, 근거 선택, 다운로드를 확인한다.
검증한 화면·동작과 아직 연결되지 않은 API를 PR에 구분해 적는다. 팀 공용 Git 규칙에
따라 기능 브랜치의 변경을 `develop` 대상 PR로 검토하며 `main`에는 직접 반영하지 않는다.
