# 아이디어 검토실 실행·시연 가이드

```powershell
python -m pip install -r requirements-ui.txt
python -m streamlit run frontend/app.py --server.address 127.0.0.1 --server.port 8504
```

1. 처음 화면에서 아이디어를 입력하거나 왼쪽의 **예시 불러오기**를 누른다.
2. **분석 브리프**에서 문제·기술·고객을 필수 입력하고 확정한다. 예시의 모든 문구는 수정할 수 있다.
3. **조사 노트**의 시장·기업, 특허·기술, 연결해서 보기 탭을 확인한다. 근거 선택 상자에서 인용문과 한계를 읽는다.
4. **구현 비용**에서 수량·단가·근거·납기를 편집하고 **비용 반영하기**를 누른다. 행 추가·삭제가 가능하다.
5. **종합 보고서**에서 메모와 확인 항목을 저장한 다음 보고서를 내려받는다.

단가는 만원 단위다. 빈 단가는 미확인이고 0은 사용자가 입력한 0원이다.
세금·배송·설치·개발·운영비는 입력한 항목만 합산하며, 소계는 총사업비가 아니다.
예시 수정 시 가상 결과·비용·검토 메모를 초기화하므로 이전 작업은 먼저 다운로드한다.
입력과 메모는 현재 세션에만 유지된다. 화면을 이동하기 전에 각 화면의 저장·확정 버튼을 누른다.

현재 실제 AI 분석·검색·PDF 처리·가격 수집은 미연결이다. 예시의 자료와 가격은 시연용이다.
[화면 구성과 후속 연결 항목](idea-workspace-ui.md)을 참고한다.
