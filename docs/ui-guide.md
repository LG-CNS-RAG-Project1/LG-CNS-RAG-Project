# 아이디어 사업 검토 화면 실행·시연

```bash
docker compose up -d ui      # make ui → http://localhost:8505
```

Docker 없이 실행할 때는 README '실행 방법'의 고정 버전 가상환경 절차(`make ui-host`)를 따른다.

## 화면 흐름

1. **아이디어 입력·초안 확인**: 한두 문장으로 시작할 수 있다. AI가 아이디어를 구조화하고 누락된 핵심 사항은 최대 두 번 질문한다. 모르는 항목은 미확인으로 남기고 진행할 수 있으며, 제목·문제·기술·고객·현재 대안·세그먼트·구성요소·가치 가설을 확인·수정한다.
2. **특허·시장 검토 — 특허 탭**: 문헌별 관련성과 구성 비교를 함께 고려해 최대 8개를 우선순위로 보여준다. 특허 비교 궤도는 처음부터 표시하며, 주의점·공통 개선 제안과 설계 대안은 본문 요약 뒤 각각 상세 팝업으로 확인한다. 대응 근거의 ‘원문 확인’은 팝업에서 열리며 분석기가 인용문에서 그대로 지정한 문자열만 강조한다. 청구항 전문·검색 미확인 목록은 접힌 영역에 둔다. 기술 비교는 등록 가능성이나 침해에 대한 법률 판단이 아니다. 특허 통계는 종합보고서에서 검색 후보와 색인 범위를 구분해 확인한다.
   **시장 탭**: 사업성 신호의 반복적인 미확인 요약 대신 기존 시장 조사 데이터의 검색 관심도 그래프, 뉴스 키워드 네트워크, 인용된 차원별 관찰을 우선 보여준다. 근거가 부족한 항목은 다음 확인 과제로 모은다. 검색된 DART 기업의 사업보고서 발췌는 회사별·연도·섹션·근거 ID와 함께 표시하고, 같은 기업의 최근 3개 사업연도 매출액·영업이익·영업이익률·당기순이익을 인접 기업 재무 현황 표로 보여 주며, 이 기업이 실제 경쟁사이거나 특허를 보유했다는 의미로 해석하지 않는다. 검색 관심도는 상대 지수이고 뉴스 네트워크는 동시 출현 관계다. 데이터·연결이 부족하면 차트를 억지로 만들지 않는다.
3. **종합 보고서**: 화면을 `보고서 요약`과 `보고서 원문`으로 나눈다. 요약에는 `executive_review`의 양쪽 근거가 연결된 교차 판단, 특허·시장별 사실과 상태, 다음 확인, 특허 검색 후보·색인 통계를 배치한다. 한 영역이 없거나 연결 판단이 없으면 통합 결론을 보류한다. `보고서 원문`에는 상세 원문과 인용 추적, 비용 분석·메모, 다운로드·기록 보관을 둔다. 접힌 **시장 맥락 · 참고 자료**에는 현재 `MarketReport`의 DART 근거, 검색 관심도 흐름, 키워드 동시 출현 네트워크와 차원별 근거 상태를 표시한다. DART 기업과 특허 출원인의 관계는 확인되지 않으면 미확인으로 표시한다. 검색 관심도는 기준어 대비 상대 지수이고, 네트워크는 뉴스 제목·요약의 동시 출현이므로 둘 다 수요·인과 증거로 해석하지 않는다. 시장 계약에 값이 없으면 차트나 수치를 만들지 않는다.

`OPENAI_API_KEY`가 있으면 초안 구조화와 실제 분석 호출에서 API 비용이 발생할 수 있다. 시작·재시도 버튼에 비용 안내를 표시한다. 분석 중에는 회전 표시와 실제 경과 시간을 보여주며 팝오버에서 완료된 단계 결과를 다시 열 수 있다. 단계 이동은 백그라운드 분석을 중단하지 않는다. 아이디어 수정은 분석을 취소한 뒤에만 가능하며 이미 외부로 전송된 요청은 즉시 중단되지 않아 비용이 발생할 수 있다. 특허 조사가 먼저 끝나면 결과를 보여주고 시장 조사를 이어 실행하며 각 영역의 결과·오류 상태는 분리해 보존한다. 키나 실제 색인이 없으면 실분석을 성공한 것처럼 보이지 않으며, 예시 입력 경로는 가상 자료임을 각 조사 화면에서 표시한다.

보고서 수요 `확인` 표시는 직접 고객 검증 근거가 없으면 허용되지 않는다. 기사·기업 보도자료만 있으면 산업 신호로 분류한다. 특허 검색 결과가 없으면 비유사 또는 등록 가능으로 해석하지 않는다. 구조화 입력을 바꾸면 이전 조사 결과는 폐기하고 다시 조사해야 한다.

## 긴 결과 화면의 바로가기

상단에는 IdeaLens 로고만 두고, 화면 오른쪽의 작은 바로가기 바에서 홈·아이디어·특허·시장·보고서와 내 기록으로 이동한다. 현재 단계는 강조하고 아직 볼 수 없는 결과는 비활성화한다. 분석 중에는 완료된 단계만 읽기 전용으로 열며 새 분석을 실행하지 않는다. ‘맨 위로’는 현재 화면의 스크롤만 올린다. 좁은 화면에서는 바가 하단으로 이동하며 본문 끝에 여백을 둔다.

홈·소개·차별점·기록에서는 고정 바로가기 바를 통해 홈·서비스 소개·차별점·내 기록과 조사 시작/계속을 제공한다. 처음 홈에는 돋보기 외의 조사 시작 버튼을 추가하지 않는다. ‘조사 계속’은 마지막에 보던 단계로 돌아가며 입력·분석 결과를 초기화하지 않는다. 페이지를 바꾸면 이전 스크롤 위치를 없애고 맨 위에서 열며, 소개 아래의 중복 홈 버튼은 두지 않는다. 로그인 전에는 바로가기를 표시하지 않는다.

## 홈과 기록

홈 돋보기로 조사를 시작한다. 서비스 소개·왜 IdeaLens인가·내 기록은 독립 메뉴다. 첫 방문에는 윗줄 → 아랫줄 → 두 줄 유지 → 제목 이동 → 메뉴·문서 → 돋보기 순서로 나타난다. 제목 복제본으로 교체하지 않고 같은 제목을 이동하며, 이미지·글꼴 준비 대기를 짧게 제한한다. 클릭·스크롤·키 입력·창 크기 변경 시 최종 배치로 마무리하고, 동작 줄이기 설정에서는 생략한다. 최초 방문 연출은 같은 세션에서 반복하지 않으며 새로고침하면 다시 표시한다. 내 기록은 현재 세션 최대 20개와 JSON 파일로 보관한다. 세션 종료 시 사라질 수 있으며 계정별 DB 기록은 제공하지 않는다. 기존 기록 파일도 불러올 수 있다.

## 실행 중 표시

특허·시장·최종 작성의 실제 상태와 경과 시간을 표시한다. 완료된 탭으로 이동해도 백그라운드 작업은 계속된다. 결과가 준비되면 현재 화면에서 확인하거나 종합 보고서로 직접 이동하며 자동 화면 전환은 하지 않는다. 부분 실패는 다른 영역 결과를 보존하고 재시도 안내를 제공한다. 진행률을 임의의 백분율로 추정하지 않는다.

## 시각화 데이터

화면은 정제·검색 이후 반환된 구조화 모델을 그대로 사용한다. `frontend/report_overview.py`의 화면 계약에 판단·근거·다음 행동과 기존 시장 참고 데이터를 투영하며 사업성 점수를 새로 만들지 않는다. 실제 검색 관심도 월별 상대 지수와 키워드 네트워크 좌표만 시각화한다. DART 공시의 기업·사업연도·섹션·인용 ID를 유지한다. PDF는 보고서 원문과 부록을 내보내며 화면 차트는 포함하지 않는다.
