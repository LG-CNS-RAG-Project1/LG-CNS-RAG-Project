# IdeaLens 조사 화면 실행·검토

```bash
python scripts/idealens.py setup
python scripts/idealens.py ui
```

Docker Desktop을 먼저 실행한다. `.env` 변경 후에는 `ui --recreate`로 컨테이너를 재생성한다. 키를 넣기 전에 실행한 컨테이너는 새 키를 자동으로 읽지 않는다.

홈은 서비스 소개·이용 안내·내 기록과 하나의 조사 시작 버튼을 제공한다. 조사 시작 전에는 입력 폼이나 단계 버튼이 나타나지 않는다.

1. **아이디어 구체화:** 아이디어 작성 → AI 초안·재질문 → 구성·질문 확인을 같은 단계 안에서 전환한다. 구성과 질문을 확인해 조사를 시작한다.
2. **특허·시장 검토:** 실제 분석은 실행 버튼을 누를 때 API를 호출한다. 두 영역은 나란히 표시하고 문헌 선택으로 한 건씩 읽는다. 질문별 연결 검토는 별도 탭에 있다. 시연은 예시 자료와 편집 기능을 유지하며 각 목록 안에서 스크롤한다.
3. **종합 보고서:** 한눈에 보기에서 기존 질문별 결과와 인용 근거 건수를 확인하고, 원문 탭에서 전체 내용을 읽는다. 비용·메모는 보조 자료다. PDF 파일 준비 후 다운로드하거나 Markdown을 바로 내려받는다.

입력이나 질문을 바꾸면 다시 확정해야 한다. 질문만 바뀌었으면 기존 조사 자료를 재사용한다. 분석 내용의 새 요약·시각화는 후속 데이터 계약에 맞춰 연결할 범위다. 근거 건수는 품질이나 시장성 점수가 아니다.

**내 기록:** 보고서에서 보관한 결과는 현재 세션에서 최대 20개까지 볼 수 있다. 계정별 영구 저장은 연결하지 않았으므로 기록 JSON을 개인적으로 내려받아 보관한다. 새 세션에서 JSON을 불러오면 보고서·부록을 볼 수 있지만 조사 실행 상태나 API 설정을 복원하지 않는다. 기록에 아이디어·분석 내용이 담기므로 공유 범위를 직접 확인한다.

키가 없는 경우 예시 시연만 가능하다. 실제 분석에는 OpenAI 및 필요한 KIPRIS 키·색인이 필요하다. 공용 Chroma를 사용하면 기존 팀 자료를 읽으며, 화면 검토를 위해 수집·색인을 다시 실행할 필요는 없다.
