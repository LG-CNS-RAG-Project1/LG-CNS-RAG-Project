# 현재 화면 기준

현재 실행 UI는 [빠른 조사 UI](quick-research-ui.md)의 4단계 구조를 따른다. 아래 내용은 이전 구성 또는 후속 확장 검토 자료이며 현재 단계·배치 설명으로 사용하지 않는다.

# 아이디어 검토실 — 로컬 UI 구성

## 사용자와 목적

신제품·사업 아이디어를 검토하는 기획자와 개발팀이 시장 수요, 관련 기술, 구현 비용을
같은 아이디어 기준으로 비교하고 다음 조사 과제를 정리하는 작업 공간이다.
특허 분석만 수행하는 서비스나 출원 대행 화면으로 범위를 한정하지 않는다.

## 화면 흐름

아이디어 한 줄 → 분석 브리프 확정 → 시장·기업 / 특허·기술 / 연결해서 보기
→ 구현 비용 → 종합 보고서

| 화면 | 사용자가 하는 일 | 남는 결과 |
|---|---|---|
| 시작하기 | 아이디어 입력 또는 예시 불러오기 | 조사할 아이디어 |
| 분석 브리프 | 문제·기술·고객·차별점·수익 방식 확인 | 사용자가 확정한 범위 |
| 조사 노트 | 조사 관점별 비교와 근거 읽기 | 근거·가설·미확인 구분 |
| 구현 비용 | 장비·부품·설치 등의 수량·단가·납기 입력 | 부분 소계와 미확인 항목 |
| 종합 보고서 | 요약 검토, 메모, 다음 조사 체크, 다운로드 | 팀 검토용 Markdown 문서 |

시장과 특허를 연결하는 예시: 고객이 설치 중단 시간을 중요하게 여긴다는 가설을 세운다.
기존 라인에 추가 설치할 기술 구조를 검토하고, 관련 문헌과 장착·설비 연동 견적을 함께
조사한다. 이 연결은 검증해야 하는 가설이며 특허 존재를 수요·구현 가능성의 증거로 쓰지 않는다.

## 참고한 공개 화면

- [타날리시스](https://tanalysis.co.kr/): 구성요소 비교, 원문 근거, 검토 범위 공개라는 흐름 참고.
- [비즈코파일럿](https://bizcopilot.co.kr/patent): 간단한 아이디어 입력과 초안 확인 단계 참고.
- 로고·이미지·문구·성능 수치·가격·법률 안내를 복제하지 않는다.

흰 배경, 회색 구획, 절제된 파란색으로 작업 화면을 구성했다. 홍보용 카드와 장식보다
표·문서·인용문을 우선한다. 좁은 화면에서는 근거 패널을 본문 아래에 배치하며 표는
영역 안에서 가로 스크롤한다.

## 현재 동작과 경계

- 브리프는 사용자가 직접 작성한다. AI 구조화, 실제 자료 수집, 하이브리드 검색은 UI에 미연결이다.
- 기본 예시만 가상 시장 메모·기업 자료·특허 요약과 가격 가정을 표시한다.
- 예시 브리프를 변경하면 가상 결과를 표시하지 않고 비용·검토 메모를 초기화한다.
- 비용은 수량 × 단가의 합이다. 빈 금액은 0원이 아닌 미확인이다. 음수·비정상 수량은 반영하지 않는다.
- 소계는 총사업비가 아니다. 배송·세금·설치·운영 등은 명시적으로 입력한 항목만 포함된다.
- 보고서는 확정 브리프, 예시인 경우 조사 내용과 근거, 반영한 비용, 저장한 검토 메모를 포함한다.
- 세션이 끝나면 입력을 잃을 수 있다. 영구 저장·로그인·팀 공동 편집·PDF 입력·출원 기능은 구현하지 않았다.

## 백엔드 연결 시 필요한 계약

1. 브리프의 필수 항목은 아이디어 이름·문제·기술·고객으로 둔다. AI가 제안한 내용과 사용자 확정값을 분리한다.
2. 시장 근거에 출처·발행일·지역·원문 위치를, 특허 근거에 공개번호·구획·청구항·법적 상태 확인 여부를 연결한다.
3. 키워드 검색·의미 검색·재정렬은 동일 질문·동일 자료로 평가한다. UI에 추정 정확도를 표시하지 않는다.
4. 가격에는 품번·통화·가격 기준일·수량 조건·세금·배송 포함 여부·견적 출처·납기 확인일을 받는다.
5. 각 조사 영역의 완료·자료 부족·검색 결과 없음·오류를 별도로 받아 부분 실패를 전체 완료로 표시하지 않는다.
6. 사실·사용자 주장·AI 해석·검증 가설·미확인을 분리하고, 근거가 없으면 사업성 점수를 만들지 않는다.

## 실행과 검증

```powershell
python -m streamlit run frontend/app.py --server.address 127.0.0.1 --server.port 8504
python -m pytest tests/test_workspace_ui.py
```

`frontend/workspace.py`는 화면 모델과 비용·보고서 함수를, `frontend/app.py`는 화면과 세션을 담당한다.
기존 `frontend/demo.py`는 기업 비교 예시 모델을 보존하며 현재 화면에서는 사용하지 않는다.
