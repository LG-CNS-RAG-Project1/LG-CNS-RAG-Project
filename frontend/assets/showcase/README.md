# 소개 화면 예시 교체

`manifest.json`은 ‘왜 IdeaLens인가 → 화면 예시·검증’에서 사용하는 이미지·설명을 관리한다. 화면 동작과 분석 코드를 변경하지 않고 이미지와 설명만 교체한다.

1. 실제 캡처에서 키·브라우저 탭·개인정보를 제거한 뒤 이 폴더에 PNG/JPG 파일을 둔다.
2. 해당 `examples` 항목의 `image`를 새 파일명으로 바꾼다.
3. `kind`를 `capture`로 바꾸고 `context`에 분석 시점·예시 입력·실제/가상 자료 여부를 명시한다.
4. `caption`, `look_for`, `meaning`, `limit`를 화면 내용에 맞게 갱신한다. 구성 예시와 실제 기능을 혼동하지 않게 한다.
5. `experiments`의 `image`는 확정된 실험 캡처가 있을 때만 지정한다. `context`에는 모델·자료 범위·질문·평가 조건과 표본 수를 명시한다. 성능 개선을 주장하려면 같은 비교 조건과 사람 검토 여부를 확인한다.

초기 SVG는 화면 구성을 설명하는 도식이다. 실제 결과·특허 도면·성능 측정 캡처가 아니다. 이미지 경로는 이 폴더 안의 파일만 허용하며, 키나 결과 원본 데이터는 이 폴더에 넣지 않는다.
